# 知乎回答写作规范

## 内容原则

- 开头直接回答问题，先给结论或明确立场。
- 用现有回答识别遗漏、争议和证据缺口，不复制其表达或结构。
- 区分事实、推断和个人经验；无法核实的内容明确标注不确定性。
- 涉及数据、医学、法律、金融或时效性事实时补充可靠来源与日期。
- 避免为了互动量制造夸张结论、虚构经历或人身攻击。

## 结构与语气

- 一般回答控制在 500–2000 字，复杂主题按必要深度展开。
- 使用二到四级 Markdown 标题组织长文；编译器会映射为知乎支持的标题层级。
- 语气专业、自然、具体，避免空泛套话和连续反问。
- 示例、代码、表格和图片只在能提升理解时使用。

## 发布前检查

- 确认回答的是页面上的准确问题，而不是仅匹配关键词。
- 检查事实、链接、代码和引用，移除真实隐私数据。
- 检查图片版权、可读性和必要的说明文字。
- 对照预览确认账号、问题 ID、新建或更新模式、正文摘要和设置。
