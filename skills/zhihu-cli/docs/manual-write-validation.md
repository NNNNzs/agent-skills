# 写操作人工验证清单

自动测试不对真实知乎账号执行写操作。只有测试账号所有者明确同意时，才按以下顺序逐项验证；每项先 preview，再人工核对并 apply/publish。

## 通用检查

- 确认 `auth whoami` 是专用测试账号。
- 确认 stdout、stderr 和 `--verbose` 均不含 Cookie、headers、请求正文或二维码 token。
- 确认无 `--confirm` 时不会产生写请求。
- 修改正文、标题、话题、图片或远端状态后，旧令牌必须失效。
- 模拟 500、超时和连接中断时，POST、PUT、PATCH、DELETE 只能发送一次。

## 互动

- 对测试回答预览赞同、执行、再次执行并检查幂等结果。
- 预览取消赞同并执行。
- 对测试问题重复验证关注和取消关注。

## 内容

- 回答：纯 Markdown、新回答、更新已有回答、本地图片、草稿和正式发布。
- 提问：纯文本路径，以及带本地图片的统一发布适配器路径。
- 想法：纯文本、多图、上传失败和发布失败。
- 文章：专栏 draft/update/publish 路径，以及带图统一发布路径。
- 所有内容检查最终 HTML 不含 `file:` 或 `pending.invalid`。

## 删除

- 分别预览并删除测试账号自己的问题、想法和文章。
- 对他人对象、匿名对象、类型不匹配对象和无法读取对象确认 CLI 拒绝删除。
- 预览后修改远端对象，再确认旧令牌失效。

## 清理

- 删除本轮创建的测试内容。
- 执行 `auth logout` 时确认新旧配置登录态被清理，临时二维码不存在。
- 不保留包含账户内容、响应正文或凭证的测试日志。
